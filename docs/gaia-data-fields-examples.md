# Gaia DR3: 1天体につきどんなデータが紐づいているか

`gaiadr3.gaia_source`テーブルの実例3件。等級フィルタ・ラスター化パイプライン
(`docs/gaia-magnitude-pipeline-plan.md`)で使う予定のフィールドを中心に抜粋。

## 主なフィールドの意味

| フィールド | 意味 |
|---|---|
| `source_id` | Gaiaの一意な天体ID |
| `ra`, `dec` | 赤経・赤緯 (deg, 参照元期 2016.0) |
| `parallax`, `parallax_error` | 年周視差 (mas)。距離[pc] ≈ 1000 / parallax[mas] |
| `pmra`, `pmdec` | 固有運動 (mas/yr) |
| `radial_velocity` | 視線速度 (km/s)。測定できていない天体も多い |
| `phot_g_mean_mag` | G バンド等級(今回のラスター化で使う「明るさ」の主指標) |
| `phot_bp_mean_mag`, `phot_rp_mean_mag` | BP(青)・RP(赤)バンド等級 |
| `bp_rp` | 色指数(BP-RP)。正で赤い(低温)星、負で青い(高温)星 |
| `teff_gspphot` | GSP-Photパイプラインによる推定有効温度(K) |
| `ruwe` | 解の質指標。1.0前後が良好、大きいほど連星や測定不良の疑い |

## 例1: シリウス — 明るすぎる星の落とし穴

シリウス(実視等級 V ≈ -1.46、全天最輝星)の位置(RA=101.287, Dec=-16.716)を
検索して見つかった最近傍レコード:

| フィールド | 値 |
|---|---|
| `source_id` | 2947050466531873024 |
| `parallax` | 374.49 mas → 距離 ≈ 2.67 pc(実際の距離2.64 pcとほぼ一致) |
| `pmra`, `pmdec` | -461.6, -914.5 mas/yr(シリウスの実際の固有運動と桁・符号が一致) |
| `phot_g_mean_mag` | **8.52**(実際は約-1.46のはず) |
| `ruwe` | 2.42(1.0前後が正常、これはかなり悪い) |

視差と固有運動は本物のシリウスと一致するので同一天体のレコードだが、
**等級だけ明らかにおかしい**。これはGaiaの検出器が明るすぎる星(目安
G≲3等)で飽和し、測光(場合によっては測光そのもの)が信頼できなくなる
既知の制限。ベテルギウスでも同様の現象を確認した(検索範囲内に本来の
0.5等の記録が見当たらず、無関係な暗い伴星らしきレコードが最近傍にヒット)。

→ 今回のラスター化パイプラインでは、**最も明るい肉眼等級の星は
`phot_g_mean_mag`をそのまま信用できない**可能性がある。必要なら
Hipparcos/Yale Bright Star Catalogなど別カタログでの補完を検討する
(現時点では保留、`docs/gaia-magnitude-pipeline-plan.md`のスコープ外)。

## 例2: 高温な青い星

`phot_g_mean_mag`が4〜6等、`bp_rp<-0.1`(青い)、質の良い(`ruwe<1.2`)星を
検索して見つかった例:

| フィールド | 値 |
|---|---|
| `source_id` | 5899408305748518528 |
| `ra`, `dec` | 219.472, -49.426 |
| `parallax` | 9.348 mas → 距離 ≈ 107 pc |
| `pmra`, `pmdec` | -28.9, -29.2 mas/yr |
| `phot_g_mean_mag` | 4.00 |
| `bp_rp` | -0.19(青い) |
| `teff_gspphot` | 13,985 K(高温、青白い星に対応) |
| `ruwe` | 1.14(良好) |

## 例3: 低温な赤い星

同条件で`bp_rp>1.3`(赤い)を検索した例:

| フィールド | 値 |
|---|---|
| `source_id` | 2940472157174944128 |
| `ra`, `dec` | 99.473, -18.238 |
| `parallax` | 6.788 mas → 距離 ≈ 147 pc |
| `pmra`, `pmdec` | -7.2, -8.8 mas/yr |
| `radial_velocity` | -1.09 km/s |
| `phot_g_mean_mag` | 4.10 |
| `bp_rp` | 1.31(赤い) |
| `teff_gspphot` | 4,841 K(低温、オレンジ〜赤色の星に対応) |
| `ruwe` | 1.03(良好) |

例2・3を見比べると`bp_rp`(色指数)と`teff_gspphot`(推定温度)が矛盾なく
連動しているのが分かる — 将来的に星の色(青白い恒星 vs 赤い恒星)を
ラスター画像に反映したくなった場合、`bp_rp`が使えそうというヒントになる。
